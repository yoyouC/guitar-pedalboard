# 音色广场 V1 需求基线

状态：已确认（2026-08-29）。本文件作为后端架构与实施规划的输入；它不选择框架、数据库、搜索服务、认证供应商或部署平台。

领域词汇以 [`CONTEXT.md`](../CONTEXT.md) 为准，关键边界见 ADR-0012 至 ADR-0019。

## 1. 目标与规模

V1 完成“创作者发布完整 Rig → 访客发现并应用 → 成员点赞”的闭环，并支持预设合集、Remix 来源和最低限度社区治理。产品按国际市场优先的公开小型社区规划，初始容量假设约 1 万成员、10 万个公开广场预设；提供中英文界面，但不承诺中国大陆网络可达性或本地合规部署。

## 2. 角色与身份

- 访客无需登录即可浏览、搜索、筛选、查看和应用公开内容。
- 成员使用本站独立身份；首期通过邮件魔法链接或 Google 登录，不保存密码。
- TONE3000 是成员可选绑定的外部模型服务，不承担本站身份、作品归属或权限。
- 成员公开资料包含稳定内部 id、唯一 handle、显示名以及可选的供应商头像和简介；不接受任意头像上传。
- 同邮箱身份不静默合并；绑定或合并需再次验证原邮箱。handle 最多每 90 天修改一次，旧 handle 永久保留给原成员并跳转到新 handle。
- 一个作品只有一个所有者；V1 不支持共同作者、团队账号或所有权转让。

## 3. 内容模型

### 3.1 广场预设与修订

- 广场预设是从完整 canonical Rig 显式发布的稳定作品，不接受局部效果链或单模块发布。
- 作品保存可变的标题、介绍、标签、可见性和当前修订引用。
- 每次 Rig 变化创建不可变修订；标题、介绍和标签修改不创建声音修订。
- 普通作品链接展示当前修订；修订永久链接始终指向同一声音。回退通过复制旧修订创建新修订。
- 标题必填且最多 80 字符；介绍可选且最多 2,000 字符；只接受纯文本。
- 每个作品必须选择 1–5 个受控标签。

### 3.2 预设合集

- 预设合集是有稳定身份、但成员列表和顺序可变的策展作品；V1 不保存合集版本历史。
- 每个合集条目固定引用具体预设修订，不跟随原作品的当前修订自动变化。
- 合集可收录他人的公开预设并保留原作者；自己的 Unlisted 预设只能进入自己的 Unlisted 合集。
- 引用作品撤回后，合集保留不可用占位，不自动删除或替换。
- 合集也使用标题、介绍和 1–5 个受控标签，并可独立获得点赞和排名。

### 3.3 来源与 Remix

- 从别人的修订加载的来源关系随本地保存和继续编辑保留，再发布时创建新的 Remix 作品。
- 从自己的作品继续编辑，默认发布为该作品的新修订。
- 无广场来源的本地 Preset 创建新作品。只有从空白或出厂 Rig 明确开始才没有来源。
- Remix 永久记录来源作品和来源修订；源作品撤回或作者注销不级联删除 Remix。

### 3.4 可见性与生命周期

- Public 内容进入广场、站内搜索和搜索引擎；Unlisted 内容只通过直接链接访问并标记为不被搜索引擎收录。
- 作者可主动撤回并恢复自己的内容，原链接、修订和点赞继续有效。
- 管理员隐藏的内容只有管理员可以恢复。
- TONE3000 资源失效不会自动撤回作品；详情页标记外部依赖不可用。

## 4. 资源边界

- 内置资源可以发布和直接复现。
- TONE3000 只保存 tone/model 引用，详情页必须提示外部依赖；本站不镜像模型。
- 本机 NAM 和自定义 Cab IR 不可发布，也不上传。
- V1 不上传预设封面、音频试听或任意用户图片；详情视觉从 Rig 数据生成。
- 发布前必须预览并校验 schema、资源依赖、必填元数据、来源和条款；失败时不创建半成品作品。

## 5. 发现、搜索与标签

- 一个搜索入口分别展示预设、合集和创作者；默认展示预设。
- 搜索覆盖标题、介绍、成员 handle 和标签，支持大小写、全半角与常见重音归一化、前缀匹配和基础拼写容错。
- 预设可按从 Rig 派生的 Pedal、Amp、Cab、资源依赖和发布时间筛选；不搜索具体旋钮参数或任意 Rig JSON。
- 标签由平台维护，使用稳定 id、中英文名称和搜索别名，按音乐风格、场景、音色特征、乐器等维度组织。
- 标签不硬删除；可停用或合并，既有内容和搜索别名迁移到目标标签。
- V1 不做向量语义搜索、个性化搜索或推荐。
- 列表与搜索使用稳定游标分页，并以不可变 id 作为最终排序键。

## 6. 点赞与排行榜

- 成员可对他人的广场预设和预设合集分别点赞或取消点赞；每人每对象最多一个有效点赞，不能自赞。
- “我的点赞”仅本人可见，V1 不另建 Favorite 或公开点赞动态。
- 最新榜按首次发布时间；最受欢迎榜按有效总点赞；趋势榜主要依据近期新增有效点赞并时间衰减。
- 被封禁成员的点赞不进入公开统计和排名。公开统计、搜索和榜单允许几十秒最终一致；当前成员自己的点赞状态立即反馈。
- 排名不使用浏览量、应用次数或演奏行为。

## 7. 应用与兼容性

- 应用广场预设前在浏览器会话中创建临时恢复点；应用不会自动保存为本地 Preset。
- 后端只接受受支持且能无损规范化的 Rig schema。未知字段或有损迁移导致发布被拒绝并提示升级。
- 旧客户端无法忠实读取未来修订时展示升级要求，不忽略字段后伪装应用成功。
- 已移除或不受支持的内置器材不会令历史修订被改写；客户端标记不兼容，可通过手动替换产生新修订或 Remix。

## 8. 治理与账号生命周期

- 已验证邮箱的成员可以举报；另提供无需登录的正式侵权通知渠道。
- 管理员可以维护标签、隐藏或恢复内容、封禁或解封成员、处理举报和一次申诉，并留下审计记录。
- 管理员不能查看登录令牌、魔法链接或第三方凭据，也不能冒充成员或占有其作品。
- 注销立即撤回成员内容并进入 30 天恢复期；期满删除资料、身份、作品正文、修订 Rig 和点赞，仅保留来源占位及必要审计。
- 成员可以导出自己的平台数据为机器可读 JSON。

## 9. 系统与隐私边界

- 浏览器拥有本地 Rig、Preset、Snapshot、MIDI 配置、音频设置和本机资源。
- 广场后端拥有成员、作品、修订、合集、标签、点赞、举报和治理记录。
- 搜索索引、派生筛选字段、聚合计数和排行榜是可重建投影，不是事实源；客户端不能提交作者、计数或排名。
- 后端故障不得阻断本地 Rig、Preset、Snapshot、URL Share、音频处理和已加载内容。
- 不记录个人级匿名浏览、应用次数、音频或演奏数据。普通服务日志短期保留，治理审计按安全需要保留。
- 公开数据包括公开资料、公开作品/合集、修订、来源和聚合点赞数；邮箱、身份绑定、我的点赞、举报、申诉和审计保持私有。
- 所有写操作支持账号与网络来源限流；发布和举报要求已验证邮箱。

## 10. 非功能目标

- 正常负载下，列表、详情和搜索接口服务端 p95 小于 500ms；发布修订 p95 小于 2s；新内容一分钟内进入搜索。
- 作品、修订、权限和来源关系强一致；聚合计数、搜索和趋势榜最终一致。
- 月度后端可用性目标 99.5%；每日数据库备份，RPO 24 小时、RTO 8 小时。
- 公开作品、合集和成员主页具有稳定、可索引 URL；标题 slug 只改善可读性，稳定 id 承担身份。
- API 只服务官方客户端，V1 不承诺第三方公共 API 或外部 SLA。
- 并发修改使用乐观并发检查，不允许无提示覆盖元数据、当前修订或合集。

## 11. V1 明确不做

- 私人 Preset 云同步、多设备合并和服务端草稿
- NAM、Cab IR、封面图片、头像文件或音频试听上传
- 评论、关注、私信、共同作者、团队与所有权转让
- 付费内容、订阅和打赏
- 独立收藏系统、公开点赞动态和通知中心
- 点赞、收录或版本更新通知
- 个性化推荐、浏览/应用计数与演奏行为画像
- 第三方公共 API
- 合集版本历史
- 密码登录
- 中国大陆可用性承诺与多地域容灾

## 12. V1 验收场景

1. 访客可搜索、筛选、查看并应用公开预设。
2. 成员可登录、编辑资料并显式发布合规的本地 Preset。
3. 声音变化生成不可变修订，旧修订永久链接仍指向同一声音。
4. 加载他人作品后发布会形成带来源的 Remix。
5. 成员可创建、排序和维护固定修订的预设合集。
6. 成员可点赞和取消点赞，最新、热门和趋势榜符合既定语义。
7. 作者可撤回和恢复内容，管理员可处理举报、隐藏、封禁和申诉。
8. 不兼容 schema、缺失内置器材或失效 TONE3000 依赖均明确降级，不伪装成功。
9. 广场后端完全不可用时，本地演奏和既有本地数据仍正常工作。
10. 公开页面具有稳定、可索引 URL；Unlisted 内容不进入站内搜索或搜索引擎。
