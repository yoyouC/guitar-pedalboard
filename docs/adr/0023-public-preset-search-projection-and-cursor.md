# 公开预设搜索组合实时事实与可重建 Rig 投影

公开预设搜索只从 Public 作品读取标题、介绍、创作者 handle、受控标签及别名等实时事实，并把当前修订派生的 Pedal、Amp、Cab、资源种类及具体资源依赖身份保存在可重建投影中；TONE3000 依赖以 `tone3000:<toneId>[:<modelId>]` 精确筛选，元数据和标签修改即时可见，声音修订与发布在同一事务内更新投影。文本在应用层统一做 NFKC、大小写、重音、前缀和有限编辑距离匹配，避免把方言相关数据库扩展变成事实源。结果按发布时间和不可变作品 id 最终定序，游标绑定规范化查询、首次快照上界和最后一项身份，使后续发布不会造成页码漂移。
