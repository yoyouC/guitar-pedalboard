# 广场应用入口按音频能力降级并恢复固定修订意图

Tone 与 Collection 是否能进入 Pedalboard 由当前浏览器的真实音频能力决定，不使用屏幕宽度或设备类别做代理。最低能力集合是安全上下文、`AudioContext`、`AudioWorkletNode` 与麦克风输入 API。窄屏但具备这些能力的设备可以继续并看到体验提示；缺少能力的设备禁用应用动作，只提供指向同一公开固定修订的链接和二维码，并明确链接不会传递本机 Rig 或音频状态。

需要 TONE3000 授权时，客户端只暂存作品 id、固定修订 id 和受限的站内返回路径。弹窗授权成功后立即重算兼容性；弹窗不可用而发生整页跳转时，OAuth 回调恢复同一个固定修订页面，由页面在重新验证外部资源和音频能力后消费一次应用意图。任何阻塞项或授权失败都不会部分应用 Rig。

Collection 启动时把每个固定修订的当前兼容性冻结为会话队列状态。不兼容位置保留标题、位置和跳过原因，但不成为可激活位置；前后导航跳过它们。手动修复只把固定来源记录为当前本地 Rig 的 provenance，不伪装成已加载不兼容声音，后续发布仍按所有权生成作者自己的新 Revision 或他人的 Remix。
