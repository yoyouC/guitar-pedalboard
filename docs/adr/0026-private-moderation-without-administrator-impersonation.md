# 私有治理审计且管理员不获得成员身份

音色广场把成员举报、正式侵权通知、管理员动作和作者申诉保存在独立的治理事实表中。管理员身份由部署配置中的稳定认证用户 id 白名单判断；治理 API 只接收已验证 session 投影出的身份，不读取或返回 session、魔法链接、OAuth token、邮箱登录凭据，也不提供管理员冒充成员或转移作品所有权的动作。

管理员隐藏内容时记录治理前的 Public、Unlisted 或 Withdrawn 状态，恢复和申诉成立都回到该状态。因此 Hidden 是平台治理状态，不会把作者主动 Withdrawn 改写为 Public。作者只看到自己作品的隐藏原因与该次处理的一次申诉状态；举报队列、侵权通知联系人和包含 actor/目标/动作/原因/时间的审计记录只对管理员开放。

成员封禁只禁止社区写操作，不删除身份、作品或历史点赞事实。公开点赞计数、Popular 与 Trending 从事实表按当前成员社区状态重建，排除被封禁成员；解封后同一事实可以再次成为有效认可。封禁/解封及这三类公开认可投影在同一 PostgreSQL 事务和 advisory lock 内提交，投影失败会回滚成员状态，避免出现已封禁但排名仍长期有效的半完成结果。
