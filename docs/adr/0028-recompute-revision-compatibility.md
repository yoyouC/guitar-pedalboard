# 从修订与资源事实重算兼容性

广场只把不可变 Rig 修订、派生的资源身份和外部资源检查事实作为输入，按请求即时计算兼容性；不在作品或修订上保存另一份“兼容/不兼容”真相。发布端明确支持 Preset schema 2–5，旧 schema 只有在输入的每个字段都能无损保留时才规范化为当前 schema。未来 schema、已移除目录器材和不可用 TONE3000 资源仍保留作品与原始 Rig，但禁止声称忠实应用。

TONE3000 检查器区分可用、需要授权、不可用和未检查。删除、转私有或授权失效只是外部资源事实，不自动撤回作品。用户显式替换器材后沿既有来源规则发布：作者本人追加新 Revision，其他成员创建保留固定来源的 Remix；原修订不修改。
