# 版本化的纯点赞趋势快照

Trending 只从当前有效点赞事实、点赞时间和成员社区状态生成；默认统计最近 7 天，并以 48 小时半衰期衰减，每个有效成员点赞权重相同。窗口与半衰期是部署策略，可通过环境变量调整，不进入公开 API；浏览、详情打开、应用、音频和演奏事件既不采集，也不是重建器输入。

预设与合集在同一次重建中获得同一不可变排名版本，但写入独立快照表。公开列表游标固定排名版本、内部趋势分数和目标 id，分数不出现在响应中；后续点赞、取消、封禁或策略变化只影响下一次重建，不会令正在翻页的遍历漏项或重复。Vercel 生产任务以五分钟为目标周期，使用独立 `CRON_SECRET` 调用重建入口；点赞事实与当前成员点赞状态仍同步写入和读取，不依赖趋势投影可用性。
