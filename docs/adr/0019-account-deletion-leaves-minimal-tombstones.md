# 成员永久注销后只保留最小来源占位

成员注销后立即撤回其作品、吊销既有登录并提供 30 天恢复期；系统只快照本次注销实际改变的 Public/Unlisted 可见性，因此再次验证可以恢复这些状态，却不能越过管理员 Hidden 或恢复申请前已经 Withdrawn 的内容。治理 Restore 与申诉成立也必须先确认作者账户仍为 Active，不能在注销窗口重新公开 Hidden 正文。期满后删除个人资料、登录身份、明文历史 handle、作品正文、修订 Rig 和派生器材信息，同时移除其点赞；历史 handle 只保留 SHA-256 预留摘要，以继续阻止冒充复用而不保留可公开解析的资料。为满足既有 Remix、合集固定修订和治理外键，只保留不可反推正文的成员/作品占位。占位只能从内容擦除方向生成，普通成员或管理员接口都不能把它还原成正文。这个选择会让原作品在注销后不可恢复，却避免以“来源完整”为由无限期保存成员已经要求删除的内容。
