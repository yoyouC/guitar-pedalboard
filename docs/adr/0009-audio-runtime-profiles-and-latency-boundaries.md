# 音频档位属于设备运行时，三类时延保持独立

音频档位作为本机偏好请求浏览器的 latency 策略，不进入 Rig、Preset、Snapshot 或 Share，也不隐式改变 DSP 质量。档位切换通过未提交的新 AudioContext 完整准备 Worklet、固定链路、当前 Rig、输入与输出，成功后提交并关闭旧 Context，失败则回滚，以换取短暂停音下的状态安全。

输出估算、Rig 链路时延和电气回环往返时延具有不同测量边界，必须独立命名、展示和导出；underrun 也只能来自浏览器明确提供的音频统计。DSP 质量选项仅在具体模块能力经过 benchmark、golden、频谱与听感验证后出现，系统不得根据压力自动改档、降质或旁路 Rig。
