# 标签合并保留源身份并在单事务内迁移关系

受控标签合并不删除或复用源 id，而把源标为 Merged Tag 并永久指向一个活动目标。Preset、Preset Collection、别名和旧筛选 id 在同一事务内迁移或转发到目标，审计记录也在该事务提交；目标已包含同一内容关系时使用集合语义去重，重复执行相同合并成为无副作用成功。连续合并会把所有旧源直接扁平指向最终活动目标，搜索词从保留的源标签身份派生，因此后续编辑目标别名不会删除旧搜索兼容。Preset 与 Preset Collection 写事务在验证活动标签时持有共享行锁，避免合并或停用完成后重新写回旧关系；开发期内存 API 共享同一生命周期状态。这样比保留两套内容关系更容易维持新选择的一致性，同时避免旧链接、保存的筛选条件与历史解释失效。
